# six city 🏙️

a tiny open-world toronto you can get into trouble in.

steal cars, pull heists and run from the cops on real streets, from the harbourfront to north york ✿

## play

no build step, just serve the folder:

```
npx serve .
```

then open the page and press play.

casino rules are unit-tested:

```
npm test
```

## controls

| | |
|---|---|
| move · drive | `w a s d` |
| shoot · punch | left click |
| aim | right click |
| weapons | `1`–`6` · scroll |
| weapon wheel | hold `q` |
| talk · buy · enter | `e` |
| get in / out of a car | `f` |
| jump · handbrake | `space` |
| sprint | `shift` |
| map · teleport | `tab` |
| missions & heists | `j` |
| go to an address | `/` |
| skip an hour · weather | `t y` |
| menu | `esc` |
